# Quick Start Guide

Get UnifiedAI Hub running in minutes with this quick start guide.

## 1. Installation

### Fastest Way: Pre-built Binary

#### macOS
1. Download [Unified AI Hub.dmg](https://github.com/yourusername/unified-ai-wrapper/releases/latest)
2. Open DMG file
3. Drag to Applications
4. Launch from Applications

#### Windows
1. Download [Unified AI Hub Setup.exe](https://github.com/yourusername/unified-ai-wrapper/releases/latest)
2. Run installer
3. Launch from Start Menu

#### Linux
```bash
# Download and run AppImage
wget https://github.com/yourusername/unified-ai-wrapper/releases/latest/download/unified-ai-hub.AppImage
chmod +x unified-ai-hub.AppImage
./unified-ai-hub.AppImage
```

## 2. First Launch

1. **Open UnifiedAI Hub**
   - Application starts with horizontal layout
   - Three AI service views appear

2. **Log in to AI Services**
   - Click in each view to activate
   - Enter your credentials
   - Complete 2FA if required

3. **Choose Your Services**
   - Use dropdown menus in control bar
   - Select which AI appears in each position
   - Try different combinations

## 3. Basic Usage

### Switching Layouts
Use the layout buttons or keyboard shortcuts:
- **Horizontal**: `Cmd/Ctrl + 1`
- **Vertical**: `Cmd/Ctrl + 2`
- **Grid**: `Cmd/Ctrl + 3`
- **Four-Column**: `Cmd/Ctrl + 4`

### Selecting AI Services
1. Click dropdown arrow in any position
2. Choose from 11 available services:
   - Claude, Grok, Gemini, ChatGPT
   - Meta AI, OpenRouter, Together AI
   - Perplexity, Mistral, DeepSeek, Moonshot
3. View loads automatically with your session

### Window Controls
- **Minimize**: Click `-` or use window controls
- **Maximize**: Click `□` or drag window edge
- **Fullscreen**: Press `F11`

## 4. Pro Tips

### Productivity Shortcuts
- `Cmd/Ctrl + R`: Reload all views
- `Cmd/Ctrl + Shift + V`: Force paste (when blocked)
- Click and drag: Move window using control bar

### Session Persistence
- Your logins are saved automatically
- Close and reopen - still logged in
- Each AI service has independent session

### Layout Recommendations
- **Comparison**: Use horizontal layout
- **Workflow**: Use vertical layout
- **Multitasking**: Use grid layout
- **Wide Screen**: Use four-column layout

## 5. Troubleshooting

### Can't see AI services?
1. Check internet connection
2. Try reloading with `Cmd/Ctrl + R`
3. Restart the application

### Login issues?
1. Verify credentials on AI service website
2. Check if service is experiencing outages
3. Clear that service's session:
   - Select different AI, then reselect

### Performance slow?
1. Close unused AI positions
2. Try simpler layout
3. Restart application
