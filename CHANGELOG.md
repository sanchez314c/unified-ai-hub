# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-09-XX

### Added
- Initial release of UnifiedAI
- Single window interface for Claude, Grok, and Gemini
- Cross-platform support (macOS, Windows, Linux)
- Electron-based desktop application
- Python backend integration
- Modern UI with responsive design
- Icon assets for all platforms

### Features
- Unified chat interface for multiple AI models
- Persistent conversation history
- Dark/light theme support
- Keyboard shortcuts
- Export conversation data

### Technical
- Built with Electron 27.3.11
- Uses Python for AI model integration
- Cross-platform build configuration with electron-builder
- Icon support for macOS (.icns), Windows (.ico), and Linux (.png)
